# اللائحة التنظيمية لوحدة MEAL — MEAL Unit Bylaws

> النسخة الرقمية التفاعلية للائحة التنظيمية لوحدة المتابعة والتقييم والمساءلة والتعلم المؤسسي (MEAL Unit) — مجلس إدارة متطوعي صناع الحياة مصر — **الإصدار الأول، مشروع تأسيسي للاعتماد**.

## نبذة

هذا المستودع يحوي نسخة تفاعلية كاملة من اللائحة التنظيمية لوحدة **MEAL** (Monitoring · Evaluation · Accountability · Learning)، وهي الوثيقة المرجعية الحاكمة لعمل الوحدة داخل مجلس إدارة متطوعي صناع الحياة مصر: 16 بابًا تنظيميًا، 101 مادة، ملحقان (قرارات الاعتماد المطلوبة + أدلة التنفيذ المؤسسية).

المتدربون، أعضاء الوحدة، الإدارات المشمولة بالنطاق، والجهات المهتمة بحوكمة العمل المؤسسي — كلهم يقدروا يتطلعوا على الوثيقة كاملة ويتصفحوها ويبحثوا فيها من أي متصفح، بدون أي تثبيت.

## المميزات

- **RTL أصيل** — الوثيقة العربية بالكامل مع عرض ثنائي الاتجاه سليم للإنجليزية (MEAL, KPIs).
- **فهرس جانبي ثابت** للتنقل السريع عبر الأبواب الـ16 + الديباجة + المواد الختامية + الملحقين، مع تصفية فورية للفهرس.
- **بحث عام (Ctrl K / ⌘K)** بمعالجة ذكية للعربية (تجاهل التشكيل، توحيد الهمزات، تجريد «الـ»)، مع إبراز النتائج والقفز المباشر للمادة.
- **101 مادة كاملة النص حرفيًا** مع نسخ رابط أي مادة بزر واحد.
- **تتبّع القراءة محليًا** — علّم المواد كمقروءة، ويتحفظ تقدمك في متصفحك (localStorage).
- **طباعة / حفظ PDF** — نسخة A4 رسمية بزر واحد (عبر `print`).
- **بدون أي أدوات بناء** — HTML + CSS + JavaScript خالص؛ يُفتح مباشرة في أي متصفح.

## التشغيل محليًا

```bash
# استنساخ المستودع
git clone https://github.com/kareemshair2/meal-unit-bylaws.git
cd meal-unit-bylaws

# أي خادم ثابت يكفي، مثلاً:
python -m http.server 8080
# ثم افتح http://127.0.0.1:8080/
```

أو ببساطة افتح `index.html` مباشرة في المتصفح.
